# Simple Interest Calculator

A simple calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

* **Principal** = Initial amount of money
* **Rate** = Annual interest rate in percentage
* **Time** = Time period in years

## How to Use

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the simple interest using the formula above.

## Example

If the principal is $1000, the interest rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = $100

## Purpose

This project demonstrates how to calculate simple interest using basic programming concepts.
